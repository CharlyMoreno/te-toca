# Capturas de Te Toca

Imágenes reales de la aplicación ejecutada localmente en Chrome, a 1600 × 1000 píxeles, con una casa ficticia llamada **Casa Nido**.

| Archivo | Contenido |
| --- | --- |
| `casa-3d.png` | Vista general con cocina, baño, dormitorio, living, garaje y jardín. |
| `tareas-y-mascotas.png` | Jardín y detalle de una tarea asociada a Milo, con cuidador y puntos. |
| `mascotas.png` | Panel para consultar y personalizar perros y gatos. |

Los integrantes Ana, Nico y Vale, las mascotas Milo y Luna y todas las tareas son datos de demostración. Las imágenes se capturaron sobre una instancia local con almacenamiento independiente del entorno habitual de desarrollo. No contienen credenciales ni códigos de invitación.

Para actualizarlas, prepará un hogar de demostración, sumá los ambientes y las mascotas, cargá algunas tareas y abrilo con sesiones de navegador independientes para mostrar presencia. Esperá a que termine de cargar el 3D y a que desaparezcan los avisos transitorios antes de capturar la pantalla. Conservá los nombres de archivo para mantener los enlaces del README.
